Sandbox honesty: browser JavaScript cannot be truly sandboxed without an iframe/CSP or a hardened worker realm. This lab applies a static deny-list, injects no globals, whitelists the ctx surface, validates every returned action and caps actions per period — but it is an isolation layer, not a security boundary. Server-side execution of user code is disabled by default (ALLOW_USER_CODE=false). See src/strategy-sandbox.js and Irregularity #7.
